Асимптотика и память

Как оценивать рост времени и дополнительной памяти при увеличении входа.

Порядок роста

Зафиксируйте размер входа и операцию, которую считаете. O(g(n)) ограничивает рост сверху с точностью до константы, Ω(g(n)) — снизу, Θ(g(n)) — с обеих сторон. Худший, средний и лучший случаи описывают разные функции стоимости. Оценка памяти учитывает выделенные структуры и стек вызовов. Отдельно оговаривайте, входит ли во вспомогательную память массив результата.

ПримерВремяДополнительная память
Сумма массиваΘ(n)Θ(1)
Двоичный поиск в отсортированном массивеO(log n)O(1) в цикле
Просмотр всех парΘ(n²)Θ(1), если пары не сохраняются
Сортировка слияниемΘ(n log n)O(n) для массива

Амортизация

Когда вектор увеличивает ёмкость в постоянное число раз, отдельная вставка может копировать или перемещать все элементы. Стоимость последовательности из n добавлений остаётся O(n) благодаря геометрической сумме. Амортизированная оценка не предполагает случайный вход.

Самопроверка

Внутренний цикл для каждого i от 0 до n−1 делает i шагов. Выведите сумму 0 + 1 + … + (n−1) и объясните, почему вложенные циклы здесь дают Θ(n²).
