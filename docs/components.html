Связность и конденсация

Компоненты обычного графа, слабая и сильная связность, алгоритм Косарайю.

Три смысла связности

В неориентированном графе запустите обход из каждой ещё не посещённой вершины. Каждый запуск выделяет одну компоненту. Слабая связность ориентированного графа получается после игнорирования направлений. Сильная связность требует пути в обе стороны для каждой пары вершин компоненты.

Косарайю и граф компонент

Выполните DFS в исходном графе и запишите вершины по времени выхода. Постройте транспонированный граф, развернув все рёбра. Обходите его из ещё не посещённых вершин в порядке убывания исходного времени выхода. Один запуск выделяет одну компоненту сильной связности. Время и память O(V + E) при хранении двух списков смежности.

Если сжать каждую сильную компоненту в вершину, получится DAG. Цикл между компонентами означал бы, что все его вершины взаимно достижимы и принадлежат одной компоненте.

Самопроверка

Для рёбер A→B, B→A, B→C, C→D, D→C перечислите сильные компоненты и рёбра конденсации.
