Динамическое программирование

Состояние, переход, базовый случай и порядок вычисления.

От рекурсии к таблице

Начните с точного смысла состояния. Например, dp[i] — минимальное число монет для суммы i при неограниченном количестве монет каждого номинала. Для положительных номиналов c переход использует только меньшие суммы: dp[i] = min(dp[i−c] + 1) по всем допустимым c. База dp[0] = 0, недостижимые суммы имеют стоимость ∞.

Вычисляйте суммы по возрастанию. При n целевой сумме и k номиналах время O(nk), память O(n). Для восстановления решения храните монету, улучшившую dp[i]. Мемоизация вычисляет нужные состояния по запросу, табуляция заполняет их в заранее выбранном порядке.
