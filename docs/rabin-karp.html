21. Полиномиальный хеш и алгоритм Рабина — Карпа

Теория, примеры и иллюстрации по теме.

Материалы и примеры по пунктам

Полиномиальная хеш-функция, алгоритм Рабина-Карпа

Например

T = "abcxabcdab"

P = "abc"

Потом берем из текста все подстроки такой же длины:

abc

bcx

cxa

И для каждой такой подстроки считаем хеш. Если хеш подстроки совпал с хешем P, значит это возможное совпадение.

xab

abc

bcd

cda

По поводу букв в цифры: да, букву надо превратить в число.

dab

Можно использовать ASCII-код:

'a' = 97

'b' = 98

'c' = 99

Хеш шаблона сравнивается с хешами окон текста той же длины. Символы можно кодировать числами, например кодами ASCII. Равные хеши дают кандидата на совпадение, которое затем проверяется сравнением символов.

Это алгоритм на основе полиномиального хеша

Рабин–Карп:

каждая позиция → сравниваем числа-хеши

если числа совпали → только тогда сравниваем символы
