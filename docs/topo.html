Порядок выполнения зависимостей и обнаружение ориентированного цикла.

Материалы и примеры по пунктам

Топологическая сортировка

Алгоритм Демукрона

Подготовка: Вычисляется вектор входящих степеней для всех вершин графа.

Поиск входов: Выбираются все вершины, у которых текущая степень входа равна 0. Они заносятся в массив текущего уровня.

Топологическая сортировка упорядочивает задачи с зависимостями. Если задачу Б можно начать только после А, вершина А должна стоять раньше Б.

Обновление графа: Для каждой выбранной вершины «удаляются» все исходящие из неё ребра. Это значит, что у всех её соседей значение входящей степени уменьшается на 1.

граф должен быть направленным ациклическим (DAG)

Асимптотика в алгоритме топологической сортировки берется из того, что он основан на поиске в глубину (DFS)

Цикл: Шаги 2 и 3 повторяются для оставшихся вершин, пока все они не будут распределены по уровням.
