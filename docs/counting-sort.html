Сортировка подсчетом

На практике сортировку подсчетом имеет смысл применять, если k = O(n),

поэтому можно считать время работы алгоритма равным Θ(2n) = Θ(n)

Устойчивость метода

O(n+k) прохождение по двум массивам.

n - кол-во элементов сортировки

k - размер алфавита

Массив

Метод применяют к целочисленным ключам из ограниченного диапазона.

Целесообразно лишь тогда, когда сортируемые числа имеют ДИАПАЗОН возможных значений, который мал по сравнению с сортируемым множеством, например, миллион натуральных чисел меньших 1000.
