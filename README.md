# Конспекты по C++ и алгоритмам — 1 и 2 семестры · ИТМО ИС

Учебный конспект для первокурсников ИТМО ИС. В нём 33 главы с объяснениями и примерами на C++, а также 11 интерактивных схем, от сортировок и BFS/DFS до максимального потока и поиска КМП. Оформление использует палитру Kanagawa Wave.

Материал охватывает первый и второй семестры. Раздел практики посвящён стилю кода, CMake и GoogleTest.

## Открыть локально

Запустите сервер из корня репозитория.

```sh
python3 -m http.server 8000 --directory docs
```

Главная будет доступна по адресу [localhost:8000](http://localhost:8000/).

## Опубликовать на GitHub Pages

1. Сохраните файлы в ветке `main` на GitHub.
2. В **Settings → Pages → Build and deployment** выберите **Deploy from a branch**, ветку **main** и каталог **/docs**.
3. После публикации ссылка появится в **Settings → Pages**.

## Править главы

Исходники глав находятся в `content/`, оформление и интерактивные схемы — в `assets/`. После изменений запустите `python3 build.py` из корня и сохраните обновлённые файлы в `docs/`. Сборка использует Python 3.9 или новее и его стандартную библиотеку. Ссылки на репозиторий и сайт заданы в `site.json`.

Каждая глава в исходниках начинается со строки `@@ slug`, заголовка `#` и краткого описания `>`. Строка `!demo` подключает соответствующий тренажёр. Блок `cpp run` содержит самостоятельный пример программы. Генератор создаёт HTML, поисковый индекс и карту сайта.

В основе сайта — переработанные студенческие конспекты по C++ и алгоритмам за два семестра, заметки о CMake, GoogleTest и стиле кода, схемы стека и динамической памяти. Личные пометки преобразованы в объяснения и вопросы для самопроверки.
