# AI-помощник по конспекту

Окно «Спросить AI» открывается в самом конспекте. Помощник учитывает открытую главу, объясняет темы, разбирает учебный код C++ и проводит самопроверку по одному вопросу за ход. Ответы могут содержать ссылки на разделы конспекта. История диалога хранится в открытой вкладке.

## Запуск на своём компьютере

Из корня репозитория установите зависимости сборки, соберите сайт и перейдите в папку помощника.

```sh
python3 -m pip install -r requirements-build.txt
python3 build.py
cd ai-assistant
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
cp .env.example .env
```

В `.env` задайте `LLM_API_KEY` и, при необходимости, `LLM_MODEL` и `LLM_BASE_URL`. Запустите сервер.

```sh
.venv/bin/python -m notes_ai
```

Откройте [конспект с AI](http://127.0.0.1:8766/). Веб-сервер отдаёт собранные главы и отвечает на вопросы по адресу `/api/ai/ask`.

Чтобы использовать настройки существующего бота, передайте путь к его локальному `.env`. Можно использовать Python из его виртуального окружения, если там установлены зависимости из `requirements.txt`.

```sh
/path/to/bot/.venv/bin/python -m notes_ai --env-file /path/to/bot/.env
```

## Подключение к опубликованному конспекту

1. Запустите сервер помощника на своём хосте и предоставьте ему публичный HTTPS-адрес. Для поиска ему нужна папка `content/`. Укажите её путь через `--content`, если структура папок отличается.
2. Задайте `AI_ALLOWED_ORIGIN=https://linuxen.github.io` на сервере. Переменная `AI_ACCESS_TOKEN` позволяет ограничить доступ. Если она задана, окно помощника предложит посетителю ввести код доступа.
3. Укажите адрес сервера в поле `ai_api_url` файла `site.json`, запустите `python3 build.py` и опубликуйте обновлённые страницы из `docs/`.

Сайт передаёт API вопрос, выбранный режим, идентификатор главы и несколько последних реплик. Сервер добавляет подходящие отрывки и отправляет их языковой модели. Ключ провайдера задаётся в окружении серверного процесса. История запросов на сервере не сохраняется. Публичный API ограничивает число одновременных запросов и их частоту.

Клиент модели и лексический поиск адаптированы из исходного проекта студенческого Telegram-бота.
