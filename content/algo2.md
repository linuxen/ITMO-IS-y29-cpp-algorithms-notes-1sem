# Графы, BFS и DFS
> Представления графа, очередь BFS и стек DFS на одной схеме.

## Представления графа

Список смежности хранит соседей каждой вершины и занимает O(V + E). Матрица смежности занимает O(V²), зато проверяет наличие ребра за O(1). Список рёбер удобен, когда алгоритм несколько раз перебирает рёбра, например в Беллмане — Форде.

## Два способа обхода

**BFS** обрабатывает вершины в порядке удаления из очереди. Помечайте вершину при добавлении, чтобы она попала в очередь один раз. При единичной стоимости рёбер первый найденный путь имеет минимальное число рёбер. Храните `parent` для восстановления пути.

**DFS** идёт вдоль ветки, пока есть непосещённые соседи, затем возвращается. Стек рекурсии хранит текущий путь. Для глубокого графа можно вести явный стек кадров, каждый кадр хранит позицию следующего соседа. Оба обхода работают за O(V + E) со списком смежности.

!demo traversal

```cpp run
#include <cassert>
#include <queue>
#include <vector>

std::vector<int> Bfs(const std::vector<std::vector<int>>& graph, int start) {
    std::vector<int> distance(graph.size(), -1);
    std::queue<int> queue;
    distance[start] = 0;
    queue.push(start);

    while (!queue.empty()) {
        int vertex = queue.front();
        queue.pop();
        for (int next : graph[vertex]) {
            if (distance[next] == -1) {
                distance[next] = distance[vertex] + 1;
                queue.push(next);
            }
        }
    }
    return distance;
}

int main() {
    const std::vector<std::vector<int>> graph{{1, 2}, {3}, {}, {}, {}};
    assert((Bfs(graph, 0) == std::vector<int>{0, 1, 1, 2, -1}));
}
```

# Топологическая сортировка
> Порядок выполнения зависимостей и обнаружение ориентированного цикла.

## Входящие степени

В топологическом порядке для каждого ребра u → v вершина u стоит раньше v. Вычислите входящие степени. Добавьте в очередь вершины с нулевой степенью. Снимая u, уменьшайте степени соседей. Как только степень стала нулевой, вершина готова к обработке. Если обработано меньше V вершин, граф содержит цикл.

В алгоритме Демукрона можно обрабатывать целыми слоями: все вершины, готовые к началу слоя, независимы внутри него. Другой способ получить порядок DAG — запустить DFS и развернуть список выходов из вершин. При этом цикл можно заметить по ребру в активную вершину. Время обоих способов O(V + E).

# Связность и конденсация
> Компоненты обычного графа, слабая и сильная связность, алгоритм Косарайю.

## Три смысла связности

В неориентированном графе запустите обход из каждой ещё не посещённой вершины. Каждый запуск выделяет одну компоненту. Слабая связность ориентированного графа получается после игнорирования направлений. Сильная связность требует пути в обе стороны для каждой пары вершин компоненты.

## Косарайю и граф компонент

Выполните DFS в исходном графе и запишите вершины по времени выхода. Постройте транспонированный граф, развернув все рёбра. Обходите его из ещё не посещённых вершин в порядке убывания исходного времени выхода. Один запуск выделяет одну компоненту сильной связности. Время и память O(V + E) при хранении двух списков смежности.

Если сжать каждую сильную компоненту в вершину, получится DAG. Цикл между компонентами означал бы, что все его вершины взаимно достижимы и принадлежат одной компоненте.

# Кратчайшие пути
> Дейкстра, Беллман — Форд, Флойд — Уоршелл и выбор по типу графа.

## Релаксация

Если путь до u найден, а ребро u → v весит w, обновляем d[v], когда d[u] + w меньше текущей оценки. Храните предка при улучшении для восстановления пути.

| Условия | Метод | Время |
| --- | --- | --- |
| Все рёбра единичного веса | BFS | O(V + E) |
| Неотрицательные веса, одна стартовая вершина | Дейкстра | O(V² + E) с линейным выбором минимума, O((V + E) log V) с двоичной кучей на простом графе |
| Возможны отрицательные веса, один старт | Беллман — Форд | O(VE) |
| Нужны расстояния для всех пар | Флойд — Уоршелл | O(V³), память O(V²) |

## Дейкстра

Начните с d[start] = 0, остальные оценки равны ∞. Извлекайте вершину с минимальной оценкой и релаксируйте исходящие рёбра. При неотрицательных весах итоговое расстояние до извлечённой вершины уже нельзя улучшить. В куче с повторными записями пропускайте пару, если её расстояние устарело.

!demo dijkstra

## Отрицательные рёбра

Беллман — Форд проходит по списку рёбер до V−1 раз. Улучшение на дополнительном проходе обнаруживает достижимый отрицательный цикл. Для вершин, до которых можно затем дойти из такого цикла, конечного кратчайшего расстояния нет.

У Флойда — Уоршелла внешний цикл перебирает разрешённую промежуточную вершину k. Переход `d[i][j] = min(d[i][j], d[i][k] + d[k][j])` применяют только к конечным составляющим. Отрицательное значение `d[v][v]` сигнализирует об отрицательном цикле.

# Минимальный остов и DSU
> Прим, Краскал и структура непересекающихся множеств.

## Остов и разрез

Остовное дерево связывает все V вершин V−1 рёбрами и не содержит циклов. Минимальный остов минимизирует суммарный вес. Минимальное ребро подходящего разреза можно безопасно добавить к строящемуся остову.

Прим растит дерево из стартовой вершины. На каждом шаге он берёт самое дешёвое ребро между деревом и внешней вершиной. Реализация с матрицей стоит O(V²), а с двоичной кучей на простом графе — O(E log V) для связного графа.

Краскал сортирует рёбра и берёт очередное, если концы находятся в разных компонентах. DSU хранит представителей, объединяет множества по размеру или рангу и сжимает пути при поиске. Сортировка определяет стоимость O(E log E). На несвязном графе получится минимальный остовный лес.

# Циклы, диаметр, мосты
> Эйлеров и гамильтонов циклы, диаметр дерева и времена DFS.

## Эйлеров и гамильтонов циклы

Эйлеров цикл проходит по каждому ребру ровно один раз. Для неориентированного графа требуется связность всех вершин ненулевой степени и чётность их степеней. Алгоритм Хиерхольцера идёт по неиспользованным рёбрам и записывает вершину при откате. С указателями в списках смежности и идентификаторами рёбер время O(V + E).

Гамильтонов цикл проходит по каждой вершине ровно один раз. Условия Дирака (минимальная степень ≥ n/2) и Оре (сумма степеней каждой пары несмежных вершин ≥ n) для простого графа с n ≥ 3 достаточны. Нарушение условия само по себе не отвечает на вопрос о наличии цикла. В общем случае задача существования NP-полна.

## Диаметр дерева

Для невзвешенного дерева найдите BFS самую далёкую вершину a от произвольного старта. Второй BFS из a найдёт другой конец диаметра. Длина — расстояние между концами, время O(V). Для дерева с неотрицательными весами можно считать суммы по единственным путям обходом.

## Мосты и точки сочленения

`tin[v]` — время входа, `low[v]` — наименьшее время входа, достижимое через поддерево и не более одного обратного ребра вверх. Древесное ребро v→to — мост, если low[to] > tin[v]. Некорневая v — точка сочленения, если есть ребёнок с low[to] ≥ tin[v]. Для корня нужны как минимум два ребёнка DFS. При кратных рёбрах пропускайте родительское ребро по его идентификатору. Время O(V + E).

# Максимальный поток и паросочетания
> Остаточная сеть, Эдмондс — Карп и алгоритм Куна.

## Остаточная сеть

Поток ограничен пропускными способностями и сохраняется в промежуточных вершинах. Остаточное ребро вперёд показывает, сколько ещё можно добавить. Обратное позволяет отменить часть уже отправленного потока. Форда — Фалкерсон ищет путь из s в t по положительным остаткам, затем увеличивает поток на минимальный остаток вдоль пути.

Для целых пропускных способностей и целого начального потока каждый шаг увеличивает значение минимум на единицу. При произвольном выборе путей время O(E·F), где F — значение максимального потока. Эдмондс — Карп выбирает путь с минимальным числом рёбер через BFS, давая O(VE²). Когда увеличивающего пути нет, достижимые из s вершины задают минимальный разрез.

!demo flow

## Паросочетание

В двудольном графе паросочетание выбирает рёбра без общих концов. В Куне для каждой левой вершины ищут увеличивающую цепочку: взять свободную правую или рекурсивно переназначить её текущую пару. Множество посещённых обновляют перед каждым отдельным поиском. Время O(V_left·E).

Для сведения к потоку соедините s с левой долей, правую долю с t, а исходные рёбра направьте слева направо. Все ёмкости равны единице. Рёбра между долями с потоком 1 дают пары.

> Полиномиальный хеш, префикс-функция, Z-функция и строковый автомат.

## Как не сравнивать всё заново

Префикс-функция π[i] — длина наибольшего собственного префикса строки s[0…i], который одновременно является её суффиксом. В КМП при несовпадении переходите от текущей длины j к π[j−1]. Так сохраняется полезная часть уже совпавших символов. После полного совпадения примените тот же переход для поиска перекрывающихся вхождений. Время O(n + m), память O(m) для шаблона.

!demo kmp

## Другие методы

- Z[i] — длина совпадения префикса строки с подстрокой, начинающейся в i. Z-алгоритм хранит самый правый известный отрезок совпадения и использует его для линейного вычисления. Для поиска можно взять `pattern + separator + text`.
- Рабин — Карп сравнивает полиномиальные хеши шаблона и окон текста. Хеш окна можно получать за O(1) по префиксным хешам. Совпадение хешей требует проверки символов для точного ответа. Из-за проверок худшее время может составить O(nm).
- Строковый автомат хранит длину совпавшего префикса как состояние, а переходы по буквам можно вычислить заранее через π. Для алфавита размера σ таблица занимает O(mσ), поиск по готовой таблице — O(n).
- Бор хранит общие префиксы строк в общих узлах. Терминальная отметка отличает добавленное слово от его префикса. Поиск стоит O(L) при O(1) доступе к переходу, где L — длина слова.

# Хеш-таблицы и фильтр Блума
> Коллизии, адресация, перехеширование и вероятностная проверка.

## Разрешение коллизий

Хеш-функция переводит ключ в индекс корзины. Разные ключи могут попасть в одну корзину. При методе цепочек в корзине хранится несколько записей. При открытой адресации пробируются другие ячейки таблицы. Удалённая ячейка помечается специально, чтобы поиск мог пройти дальше по той же цепочке проб.

!demo hash

При росте коэффициента заполнения растёт число коллизий. Перехеширование выделяет новую таблицу и заново размещает элементы. При хорошем распределении ключей ожидаемое время поиска близко к O(1), в худшем случае оно O(n). Метод кукушки даёт каждому ключу несколько возможных позиций и при вставке вытесняет прежних владельцев. При цикле вытеснений потребуется перестройка.

## Фильтр Блума

При вставке выставляются несколько битов, выбранных хешами. Если при проверке хотя бы один нужный бит равен нулю, ключа точно нет. Если все выставлены, ключ может быть в наборе. Стандартный фильтр Блума допускает ложные срабатывания и не поддерживает простое удаление выставленных битов. Ключи хранятся отдельно, если нужно восстановить сами значения.
