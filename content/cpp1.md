## Первая программа

Функция `main` — точка входа. Оператор `>>` читает значение из потока, а `<<` отправляет его в поток вывода. Проверка `std::cin` позволяет заметить неверный ввод или конец файла.

```cpp run
#include <iostream>

int main() {
    int score{};
    if (!(std::cin >> score)) {
        return 1;
    }
    std::cout << (score >= 60 ? "pass" : "retry") << '\n';
}
```

## Как выбрать тип

- `bool` хранит логическое значение, `char` — символ или небольшое целое, `int` — целое, `double` — число с плавающей точкой. Размер `int` зависит от платформы. Для точной разрядности есть типы вроде `std::int32_t` из `<cstdint>`, когда реализация их предоставляет.
- `unsigned` считает по модулю 2ⁿ. Переполнение знакового целого при вычислении — неопределённое поведение. Смешение знаковых и беззнаковых значений может изменить результат сравнения.
- `42`, `052`, `0x2A` и `0b101010` задают одно число в десятичной, восьмеричной, шестнадцатеричной и двоичной системах. `'A'` — символ, `"A"` — массив символов с завершающим нулём, `'\n'` — перевод строки.
- Деление `5 / 2` даёт `2`. Дробный результат можно получить через `static_cast<double>(5) / 2`. Инициализация фигурными скобками выявляет сужающие преобразования вроде `int n{3.5}` на этапе компиляции.

## Условия, циклы, функции

`if` выбирает ветку по условию. `switch` сравнивает целое или перечисление с константами, `break` завершает ветку. `for` удобен для диапазона с понятными границами, `while` — когда следующая итерация зависит от состояния.

Объявление `int Square(int x);` сообщает компилятору сигнатуру, определение содержит тело. Перегрузки различаются параметрами. Имена видны в своей области видимости, а локальная переменная с тем же именем скрывает внешнюю.

## Адрес и псевдоним

`&value` получает адрес, `*ptr` обращается к объекту по адресу. Указатель можно переназначить и проверить на `nullptr`. Ссылка `T&` привязывается при инициализации. `const T&` полезна для доступа без копирования через этот параметр.

```cpp run
#include <cassert>
#include <vector>

void Increment(int& value) {
    ++value;
}

int main() {
    std::vector<int> values{2, 4, 6};
    int* first = &values[0];
    Increment(*first);
    assert(values.front() == 3);
}
```

## Массивы и строки

У встроенного массива фиксированная длина, индексация начинается с нуля. В параметре `int a[]` тип корректируется до `int*`, поэтому длину передают отдельно. `std::array<T, N>` хранит размер в типе, `std::vector<T>` меняет длину, а `std::span<T>` (C++20) представляет непрерывный диапазон без владения им.

Арифметика указателей допустима внутри одного массива и до позиции за его концом. Последнюю позицию нельзя разыменовывать. `sizeof(array)` в месте объявления даёт размер всего массива, а `sizeof(ptr)` — размер самого указателя.

C-строка оканчивается `'\0'`. `std::string` владеет своей памятью и хранит длину. `std::string_view` ссылается на существующие символы. Проверяйте, что исходная строка переживает все обращения через view.

## Массивы и функции

В двумерном массиве `int table[2][3]` хранится два массива по три числа. При передаче функции как `int table[][3]` размер строки нужен, чтобы правильно перейти к следующей строке. Указатель на функцию `int (*operation)(int)` можно вызвать как `operation(5)`, если он указывает на функцию с соответствующей сигнатурой.

# Структуры, представление и память
> Как данные размещаются в объектах и когда их можно использовать.

## Структуры, объединения, перечисления

`struct` объединяет несколько полей. Доступ через объект записывается как `point.x`, через указатель — `ptr->x`. Между полями возможны байты заполнения для выравнивания, поэтому `sizeof(Point)` может превышать сумму размеров полей.

У `union` поля используют общую память. Учитывайте активный член и правила его времени жизни. Для безопасного выбора одного из нескольких типов подойдёт `std::variant`. `enum class` задаёт именованные варианты вроде `State::kReady`.

## Время жизни

Локальные объекты обычно имеют автоматическое время хранения и уничтожаются при выходе из блока. Объекты со статическим временем хранения живут до завершения программы, `thread_local` — до завершения своего потока. Динамическое время жизни управляется через владельца ресурса.

- `new T` выделяет память и создаёт объект. Парные операции — `new` и `delete`, `new[]` и `delete[]`.
- `std::malloc` выделяет сырую память и не вызывает конструкторы, `std::calloc` дополнительно зануляет байты. Освобождение выполняет `std::free`.
- Для прикладного кода выбирайте `std::vector`, `std::string` и умные указатели, которые освобождают ресурсы автоматически. Висячие ссылки, выход за границы и повторное освобождение приводят к неопределённому поведению. AddressSanitizer помогает найти многие такие ошибки.

## Стек вызовов и динамическая память

На типичной платформе стек вызовов хранит кадры активных функций. При вызове появляется новый кадр, при возврате снимается последний добавленный. Указатель стека участвует в управлении этим пространством. Конкретное направление роста и расположение данных зависят от платформы и компилятора. Частые вложенные вызовы, глубокая рекурсия и большие локальные массивы могут исчерпать доступный стек.

Динамическая память позволяет создавать объекты, размер и время жизни которых определяются во время выполнения. Её объём ограничен доступными ресурсами процесса. Выделение через обычный `new` при нехватке памяти может бросить `std::bad_alloc`. Освобождение блока не перемещает остальные объекты автоматически, а свободные участки разных размеров могут приводить к фрагментации.

У локального `std::vector<int> values(1000)` сам объект контейнера имеет автоматическое время хранения, а его элементы размещены в отдельно выделенном буфере. При росте vector может выделить новый буфер, перенести элементы и освободить старый. При уничтожении контейнера освобождается и его буфер. Сборщик мусора ищет объекты, которые больше недостижимы из программы. В обычном C++ ресурсами управляют через время жизни владельцев и RAII.

## Представление чисел

У вещественного типа ограниченная точность. Десятичное `0.1` обычно округляется при хранении, поэтому результат вычислений может слегка отличаться от математического. При сравнении результатов используйте допуск, осмысленный для масштаба задачи.

## Этапы сборки

Препроцессор обрабатывает `#include` и условные директивы. Компилятор переводит каждую единицу трансляции в объектный код, а компоновщик объединяет объектные файлы и библиотеки. Сообщение об отсутствии объявления обычно появляется при компиляции, `undefined reference` — при компоновке.

```sh

c++ main.o calculator.o -o calculator
```

## Заголовки и имена

В заголовок обычно помещают объявления, определения шаблонов и подходящие `inline`-определения. Защитный макрос предотвращает повторное включение заголовка в одну единицу трансляции.

```cpp
#ifndef CALC_CALCULATOR_HPP_
#define CALC_CALCULATOR_HPP_

namespace calc {
int Add(int left, int right);
}

#endif
```

Пространство имён позволяет обратиться к функции как `calc::Add`. Для функций и переменных на уровне пространства имён `static` даёт внутреннюю линковку. `extern int counter;` без инициализатора объявляет переменную, определение которой может быть в другом файле. У локальной переменной `static` меняет время хранения. `mutable` позволяет изменять конкретное поле через `const`-объект, например счётчик попаданий в кеш.

## Инвариант объекта

Класс объединяет состояние и операции. Конструктор устанавливает допустимое состояние, публичные методы поддерживают его, закрытые поля позволяют контролировать изменения. Поля инициализируются в порядке объявления в классе. `this` — указатель на текущий объект внутри нестатического метода.

```cpp run
#include <cassert>
#include <stdexcept>
#include <vector>

class Scores {
public:
    void Add(int value) {
        if (value < 0) {
            throw std::invalid_argument("negative score");
        }
        values_.push_back(value);
    }

    int At(std::size_t index) const {
        return values_.at(index);
    }

private:
    std::vector<int> values_;
};

int main() {
    Scores scores;
    scores.Add(10);
    assert(scores.At(0) == 10);
}
```

## Владение ресурсом

RAII связывает ресурс со временем жизни объекта. Деструктор владельца освобождает память, файл или блокировку при выходе из области видимости, в том числе при исключении. Если поля уже управляют собой, часто достаточно **правила нуля** и автоматически создаваемых специальных функций.

При ручном управлении ресурсом проверьте деструктор, копирующий конструктор и присваивание (правило трёх), а также перемещающий конструктор и присваивание (правило пяти). Поверхностное копирование владеющего указателя может привести к двойному освобождению.

## Перегрузка операторов

Сохраняйте привычный смысл операций. `operator+=` обычно меняет объект и возвращает `T&`. `operator+` можно выразить через него с копией левого аргумента. `operator[]` часто имеет перегрузки для обычного и `const`-объекта. Постфиксный `operator++(int)` возвращает старое значение, префиксный `operator++()` обычно возвращает ссылку на обновлённый объект.

## Вызов через базовый тип

Открытое наследование моделирует отношение «является разновидностью». Виртуальная функция выбирается по динамическому типу объекта при вызове через указатель или ссылку. `override` просит компилятор проверить, что сигнатура действительно переопределяет базовый метод. Чистая виртуальная функция обозначается `= 0`.

```cpp run
#include <cassert>

struct Shape {
    virtual ~Shape() = default;
    virtual int Area() const = 0;
};

struct Square final : Shape {
    explicit Square(int side) : side(side) {}
    int Area() const override { return side * side; }
    int side;
};

int main() {
    Square square{4};
    const Shape& shape = square;
    assert(shape.Area() == 16);
}
```

## Интерфейс и реализация

Если объект удаляется через указатель на базовый класс, базовый деструктор обычно должен быть виртуальным. Передача производного объекта по значению в параметр базового типа может привести к срезке. `final` ограничивает дальнейшее наследование класса или переопределение метода.

`friend` даёт конкретной функции или классу доступ к закрытым членам. Композиция описывает отношение «содержит» и часто подходит для повторного использования реализации. Абстракция задаёт интерфейс, инкапсуляция защищает состояние, наследование выражает отношение типов, а полиморфизм позволяет работать с разными реализациями через общий интерфейс.

# Шаблоны и vector
> Обобщённые функции, классы и динамический массив.

## Параметры шаблона

`template <typename T>` позволяет написать одну функцию для семейства типов. `typename` и `class` взаимозаменяемы при объявлении типового параметра. Параметром может быть и значение, как размер в `std::array<int, 4>`. Определения шаблонов обычно видны из заголовков в точке инстанцирования.

```cpp run
#include <cassert>
#include <vector>

template <typename T>
T Sum(const std::vector<T>& values) {
    T result{};
    for (const T& value : values) {
        result += value;
    }
    return result;
}

int main() {
    assert(Sum(std::vector<int>{2, 3, 5}) == 10);
}
```

## Размер и ёмкость

`size()` — число объектов, `capacity()` — объём выделенного места в элементах. `reserve(n)` резервирует память без добавления элементов. `resize(n)` меняет размер. Добавление в конец амортизированно O(1), вставка в середину обычно O(n), обращение по индексу O(1). При перевыделении памяти инвалидируются итераторы, ссылки и указатели на элементы.
